# Intro

**BGP Security** — Examine interdomain routing security from first principles: BGP architecture, origin hijacks, route leaks, IRRs, RPKI/ROAs/ROV, BGPsec, ASPA, documented incidents, and a runnable Containerlab RPKI/ROV lab.

## How to use this part

Read sequentially for a full routing-security track, or jump straight to `31-rpki-rov-containerlab-lab.md` for hands-on RPKI validation.
