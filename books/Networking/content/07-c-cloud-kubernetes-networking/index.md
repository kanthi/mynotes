# Intro

**Cloud and Kubernetes Networking** — Bridge traditional IP networking into public cloud VPCs, Linux container primitives, CNI plugins, Kubernetes Services (`kube-proxy` vs Cilium eBPF), Gateway API, and NetworkPolicy.

## How to use this part

Read `01` for cloud VPC mental models, `02` for hands-on Linux container networking, and `03`–`04` for Kubernetes traffic and policy.
