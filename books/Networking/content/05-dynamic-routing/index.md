# Intro

**Dynamic Routing** — Design, operate, and troubleshoot dynamic routing protocols: OSPF, IS-IS, BGP, route reflectors, redistribution, BFD, RPKI ROV, Segment Routing (SRv6/TI-LFA/Flex-Algo), and graceful convergence.

## How to use this part

Start with `00`–`03` for core OSPF/BGP/policy mechanics, then explore BFD (`04`), RPKI (`05`), and Segment Routing (`06`–`06c`).
