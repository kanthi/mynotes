# Intro

**Lab Platform** — Prepare your macOS or Linux host, deploy reproducible topologies with Containerlab and netlab, and choose free network OS images before touching protocol configs.

## How to use this part

Start with your host OS guide (`01` or `02`), run through Containerlab fundamentals (`03`), and check the free image matrix (`04`) before picking a lab.
