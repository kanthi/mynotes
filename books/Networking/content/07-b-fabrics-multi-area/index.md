# Intro

**Fabrics and Multi-Area** — Scale from single-router topologies to Clos leaf-spine data center fabrics, multi-area OSPF, EVPN-VXLAN IRB and anycast gateways, BGP unnumbered (RFC 5549/8950), optical diagnostics, and lossless AI/ML Ethernet fabrics.

## How to use this part

Build the conceptual model in `01`–`05`, then advance to EVPN-VXLAN design (`06`), BGP unnumbered (`07`), and hardware/AI fabrics (`08`).
