# Intro

**Network Automation with Ansible** — A practical, production-oriented track taking network engineers from manual CLI administration to declarative, data-driven, CI/CD-verified network automation across Cisco IOS-XE/NX-OS/ASA, Juniper Junos, Fortinet FortiOS, and Arista EOS.

## How to use this part

Read Parts One through Four sequentially to master Ansible mechanics, network connection plugins, resource modules, Jinja2 templating, and Source of Truth workflows. Use Parts Five through Seven as operational blueprints for backups, upgrades, campus/WAN/security rollouts, testing, CI/CD, and AWX/AAP governance. Jump straight to the Appendices for quick syntax lookups, cross-vendor module mappings, and a runnable lab build guide.
