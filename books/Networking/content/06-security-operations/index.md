# Intro

**Security Operations and NetOps** — Operate networks as code with observability, flow export (IPFIX), BMP, STAMP, SNMPv3, Linux drop counters, YANG/NETCONF/gNMI, Source of Truth templating, Batfish/Suzieq verification, streaming telemetry, and CI pipelines.

## How to use this part

Start with `01` and `05` for live troubleshooting, then build automated pipelines with `06`–`10`.
