# Intro

**Network Forensics** — Investigate network intrusions using packet capture, behavioral analysis, SIEM log correlation, domain-specific forensics, and a hands-on PCAP triage lab with `tcpdump`, `tshark`, Zeek, and Suricata.

## How to use this part

Use `01`–`10` for methodology and SIEM integration, and `14-pcap-triage-zeek-suricata-lab.md` for immediate command-line PCAP triage.
