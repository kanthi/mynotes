## How the content is organized

Source lives under `content/`. Each first-level directory is a **part** in the sidebar:

| Folder | Role |
|--------|------|
| `content/00-intro/` | Orientation and overview |
| `content/01-foundations/` | Core material |
| `content/99-appendices/` | Optional extras (add when needed) |
| `content/_planning/` | Notes only — omitted from `octavo.yml` |

Chapter order is set in `octavo.yml`. Prefer numeric prefixes:

```text
content/01-foundations/01-getting-started.md
content/01-foundations/02-core-ideas.md
```

Override sidebar labels in `octavo.yml` or set a chapter title in YAML frontmatter:

```yaml
---
title: "Getting Started"
---
```
