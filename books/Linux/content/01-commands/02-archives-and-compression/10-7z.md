# 7z

## Overview

`7z` (from `p7zip` / `7zip`) is a high-ratio archiver supporting `.7z` (LZMA2), `.zip`, `.tar`, `.gz`, `.xz`, `.iso`, and `.cab` formats. It achieves noticeably smaller archives than `zip` or `gzip` on source trees and backups, supports AES-256 encrypted archives (including encrypted filenames), and handles multi-volume splits cleanly.

```bash
sudo apt install 7zip          # Ubuntu/Debian (or p7zip-full on older releases)
sudo dnf install 7zip-standalone # Fedora/RHEL
```

## Syntax

```bash
7z <command> [switches] <archive_name> [file_names...]
```

## Common Commands & Switches

| Command / Switch | Description |
|------------------|-------------|
| `a` | Add files to an archive (creates if missing) |
| `x` | Extract with full directory paths preserved |
| `e` | Extract all files flat into the current directory |
| `l` | List archive contents, sizes, and compression ratio |
| `t` | Test archive integrity without extracting |
| `-p[PASS]` | Encrypt archive (or supply password); omit `PASS` to prompt safely |
| `-mhe=on` | Encrypt filenames/headers too (`.7z` format only—hides file list!) |
| `-mx=N` | Compression level `0` (store) to `9` (ultra); `-mx=5` is default |
| `-v100m` | Split output into 100 MiB volumes (`.7z.001`, `.7z.002`, ...) |
| `-oDIR` | Set output directory (no space between `-o` and `DIR`!) |

## Key Use Cases

1. Create compact, encrypted cross-platform archives for off-site backups (`-p -mhe=on`)
2. Inspect and extract `.iso`, `.zip`, `.rar`, or `.7z` bundles with one tool
3. Split large archives into fixed-size chunks (`-v500m`) for upload limits or FAT32 drives
4. Verify archive integrity (`7z t`) before deleting source files

## Safety

- Passing `-pMySecret` directly on the command line exposes the password in `ps` and shell history—use `-p` without an argument to prompt interactively, or use `age`/`gpg` for automated scripts.
- Remember: `7z` does **not** preserve Unix ownership (`uid`/`gid`) or permissions/symlinks reliably on its own—for Linux backups, pair `tar` with `7z` or `zstd` (`tar -cf - dir | 7z a -si dir.tar.7z`).

## Examples with Explanations

### Create a high-compression `.7z` archive

```bash
7z a -mx=9 project-backup.7z ./project/
```

### Create an encrypted archive with hidden filenames

```bash
7z a -p -mhe=on secrets-backup.7z ./keys/
```

Prompts for a password and encrypts both file contents and the file listing (`7z l` won't reveal filenames without the password).

### List and test an archive before extracting

```bash
7z l project-backup.7z
7z t project-backup.7z
```

### Extract to a specific directory with full paths

```bash
7z x project-backup.7z -o/tmp/restore
```

Note there is **no space** after `-o`.

### Exclude build artifacts (`node_modules`, `.git`)

```bash
7z a -xr'!node_modules' -xr'!.git' repo.7z ./myrepo
```

### Split a large archive into 100 MiB parts (and extract from `.001`)

```bash
7z a -v100m dataset.7z ./dataset/
7z x dataset.7z.001
```

### Preserve Linux permissions by piping `tar` into `7z`

```bash
tar -cf - /etc/nginx | 7z a -si nginx-etc.tar.7z
7z x -so nginx-etc.tar.7z | tar -xf -
```

## Notes & Pitfalls

- `7z e` flattens all subdirectories into one folder; almost always use `7z x` instead to preserve directory structure.
- For Linux-native backups, `tar` + `zstd` is faster and preserves permissions/xattrs natively without needing `-si`/`-so`.

## Related Commands

- `tar` / `zstd` / `xz` — native Unix archiving and compression
- `zip` / `unzip` — standard cross-platform `.zip` tools
- `age` / `gpg` — modern file encryption for Unix pipelines
