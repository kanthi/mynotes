# yq

## Overview

`yq` is a lightweight, portable command-line processor for **YAML, JSON, TOML, XML, and INI**—effectively `jq` for configuration files. On Linux servers and Kubernetes/CI environments, it lets you safely query and edit `docker-compose.yml`, Kubernetes manifests, GitHub Actions workflows, and netplan configs without fragile `sed` or `awk` indentation hacks.

## Syntax

```bash
yq [options] '<expression>' [file...]
```

## Common Options

| Option | Description |
|--------|-------------|
| `-i` | Edit the YAML file **in place** while preserving comments and formatting |
| `-o json` / `-o yaml` / `-o props` | Convert output format (e.g., YAML to JSON or JavaScript/properties) |
| `-p xml` / `-p toml` / `-p ini` | Parse non-YAML input formats |
| `-r` | Raw string output (no surrounding quotes) |
| `-e` | Exit non-zero if the expression evaluates to `false` or `null` |

## Key Use Cases

1. Query nested keys in Kubernetes, Docker Compose, or Ansible YAML files
2. Update image tags or config values in place (`yq -i`) in CI/CD scripts
3. Convert between YAML, JSON, TOML, and XML in pipelines (`yq -o json | jq`)

## Safety

- Two different `yq` projects exist: Mike Farah's Go `yq` (most common, standalone binary) and Kislyuk's Python `yq` (a `jq` wrapper). Check `yq --version`—the examples below use Go `yq` (`v4+`).
- Always test without `-i` first so you can verify the exact diff before overwriting a config file.

## Examples with Explanations

### Read a nested value from a YAML file

```bash
yq '.services.web.image' docker-compose.yml
```

### Update an image tag in place (preserving comments)

```bash
yq -i '.services.web.image = "nginx:1.27-alpine"' docker-compose.yml
```

### Convert YAML to JSON (or TOML to JSON)

```bash
yq -o json config.yaml | jq '.database.host'
yq -p toml -o json Cargo.toml
```

### Merge two YAML files

```bash
yq eval-all 'select(fileIndex == 0) * select(fileIndex == 1)' base.yml override.yml
```

## Notes & Pitfalls

- Single-quote your `yq` expression (`'...'`) when the expression doesn't need shell variables; when passing a shell variable, use `env(VAR)`: `TAG=1.27 yq -i '.image = strenv(TAG)' app.yml`.
- Python `yq` uses `yq -y` and `jq` syntax; Go `yq` uses `-o yaml` and `env()`/`strenv()`.

## Related Commands

- `jq` — JSON processor
- `sed` / `awk` — line-oriented text editing (avoid for nested YAML!)
